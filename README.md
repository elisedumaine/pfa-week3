# pfa-week3
I created a Fantasy island tool. It allows the user to have fun by customizing an island through an simple and accessible interface. You can play with different natural and human made elements in the island
To run it, you have to copy and paste the script in a terminal of a 3D modelling software like Maya or Blender.
Have fun !
